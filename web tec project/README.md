# Arav Rai - Portfolio Website

A simple multi-page portfolio website made for the Web Technology subject at NorthCap University.

## About the project

This website introduces Arav Rai, a BCA student in semester 3 who is learning the fundamentals of web development and aims to become a software engineer.

## Pages

- **Home** (`index.html`) - introduction and link to the Contact page
- **About** (`about.html`) - education and career goal
- **Skills** (`skills.html`) - programming languages and web development learning
- **Projects** (`projects.html`) - portfolio project information
- **Contact** (`contact.html`) - demo contact form

## Built with

- HTML for page content and structure
- CSS for layout, colors, and responsive design
- JavaScript for the theme button and demo form response

## How to view the website

1. Download or clone this project folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to move between the different pages.

No installation is needed.
